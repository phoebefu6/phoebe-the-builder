====================================================================================================
COHEN'S d IS NOT THE EFFECT. IT IS ONE SUMMARY OF IT, AND THE SUMMARIES DISAGREE.
====================================================================================================

Every population below is standardised to population mean 0 and population SD 1 using its
ANALYTIC moments, then the treated group is shifted by exactly d. So the population Cohen's d
is EXACTLY d for every shape. Any disagreement between metrics is therefore not a difference
in how big the effect is - it is the metrics answering different questions.

Shapes: normal, uniform, t5, contaminated, lognormal, exponential.  Replicates: 20,000 a cell.  Reference draws for a population
truth: 20,000,000.

----------------------------------------------------------------------------------------------------
0. CALIBRATION - reproduce a known truth before reporting an unknown one
----------------------------------------------------------------------------------------------------

For NORMAL data the probability of superiority has a closed form, Phi(d/sqrt(2)). The
reference sampler must reproduce it. No other shape has a closed form, which is the whole
reason the rest of this file exists.

shape              d   P(X>Y) measured   +/- 99%   closed form   match
normal           0.2           0.55643   0.00029       0.55623      OK
normal           0.5           0.63811   0.00028       0.63816      OK
normal           0.8           0.71423   0.00026       0.71420      OK

  Calibrated on 3 of 3 normal cells.

  A 'medium' effect of d = 0.5 is taught as 'the treated case beats the control about 64% of
  the time'. That number is correct for normal data and for nothing else here. Same d.

  NOTE, and it differs from what the sibling `normality-test-trap` found about the t-TEST:
  there, symmetric non-normality was harmless and SKEW was the whole problem. Here both move
  the answer and they move it the SAME WAY - the contaminated population is perfectly
  symmetric and still reads 0.686 at d = 0.5 against normal's 0.639. The mechanism is that a
  heavy tail inflates the SD that d divides by, so a shift of 'one d' is a larger shift
  relative to the bulk of the distribution where the comparisons actually happen. Robustness
  of the TEST and robustness of the EFFECT SIZE are different questions with different answers.

  polishing the third decimal of a number whose first decimal is not settled.

3. ROBUSTNESS - one contaminated observation in a hundred
----------------------------------------------------------------------------------------------------

1% of the TREATED values are replaced with +10 SD. The outlier points the same way as the
effect, which is the charitable case - a big real response, not a data-entry error.

metric                        clean   contaminated     change
cohens_d                     0.5030         0.4968      -1.2%
hedges_g                     0.5011         0.4949      -1.2%
glass_delta                  0.5051         0.6007     +18.9%
prob_superiority             0.6384         0.6420      +0.6%
cliffs_delta                 0.2768         0.2840      +2.6%
point_biserial_r             0.2434         0.2411      -0.9%
log_odds_median_split        0.7985         0.8149      +2.1%

  Most moved:  glass_delta at +18.9%.
  Least moved: prob_superiority at +0.6%.

  The result nobody expects: GLASS'S DELTA is the metric that moves, and it is the one
  recommended precisely for the case where the treatment changes the spread. It divides by the
  CONTROL group's SD, which the contamination never touches - so the numerator grows and the
  denominator does not. Cohen's d barely moves because its pooled SD absorbs the same outlier
  that inflated the mean. The 'safer' choice is the fragile one, and the direction of the
  failure is upward: it reports a LARGER effect.

  At n = 100,000 per group the smallest effect the study is not guessing about is d = 0.0088,
  which means the treated value beats the control 50.25% of the time. That is a
  coin flip with a statistically significant lean, and it is what 'everything is significant
  at large n' actually looks like when you write it down in units a person can act on.

  A DEFECT THIS BUILD HIT AND NEARLY SHIPPED, worth recording because nothing warns you:
    scipy.stats.nct returns **nan** - not an error, not a warning - at 3 of the sample sizes probed,
    from n = 1,000 to n = 10,000. A nan is silently False in
    every comparison, so `power >= target` reads as 'not powerful enough' and a monotone
    binary search walks straight past the answer. The first version of this module reported
    that d = 0.5 needs n = 11,417 per group for 80% power. The real answer is 64.
    The fix is a normal-approximation fallback, and it is only trusted because it is measured:
    across every n where the exact form IS finite, the two formulas differ by at most
    0.016411 (at n = 5), and once df >= 400 - which is far
    below where the nan band starts - by at most 4.65e-05 (at n = 201).
    The search is now a helper that asserts its own monotonicity at both ends and raises
    rather than returning a plausible number.

5. WHAT A MEDIAN SPLIT COSTS - and the shapes where it costs nothing
----------------------------------------------------------------------------------------------------

True d = 0.4 throughout. 'null t' and 'null split' are each test's rejection rate when
d = 0, run on the same shape and n. A power comparison is only read on rows where BOTH hold a
nominal 5% - an over-rejecting test detects more of everything, so its power lead would be the
inflation restated.

  Only 6 of 12 rows are comparable at all - and the reason is itself a
  finding: the median-split test is ANTICONSERVATIVE at n = 50, rejecting a true null at
  0.0696 to 0.0736 against a nominal 0.05, on every shape tested. Before
  it costs you any power, dichotomising costs you the error rate you thought you had.

  Among the readable rows the t-test wins 2 and the median split wins 2.
    t wins on normal (n=200): the split has the power of n = 133, so 34% of the sample was thrown away.
    t wins on uniform (n=200): the split has the power of n = 72, so 64% of the sample was thrown away.
    SPLIT wins on contaminated (n=200): it has the power of n = 269, i.e. 34% MORE data than you collected.
    SPLIT wins on lognormal (n=200): it has the power of n = 295, i.e. 48% MORE data than you collected.

  NEGATIVE RESULT: 'never dichotomise your data' is advice about NORMAL data. On normal data
  it is right and the price is a third of the sample. On skewed and heavy-tailed data the
  median split is a rank method, the t-test is not, and the split WINS. The rule is real; it
  is just not a rule about dichotomisation. It is a rule about which yardstick matches the
  shape of what you measured - which is the same thing section 1 said.

====================================================================================================
WHAT TO TAKE AWAY
====================================================================================================

1. At an IDENTICAL true Cohen's d of 0.5, the probability of superiority ranges over 0.083
   across six distribution shapes. d is not wrong; it is a ratio of two numbers, and the
   denominator means different things in different shapes.
2. Reporting an effect size without saying which one, on what shape, with what interval, is
   reporting a number rather than a magnitude.
3. Glass's delta - the metric recommended when the treatment changes the spread - moves +19%
   on one contaminated observation in a hundred. Cohen's d moves about one percent.
4. At n = 100,000 the smallest effect a study can see is P(X>Y) = 0.5025. Significance stopped
   carrying information about magnitude long before that.
5. 'Never dichotomise' is a claim about normal data. Measured on skewed data it is false.
