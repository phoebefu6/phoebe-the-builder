One Data Platform

Small, exact tools for the parts of data work that quietly go wrong.

Each one started with something breaking in a real pipeline: a metric that disagreed with itself, a parser that read the same bytes two ways, a model that looked fine until it shipped. Source code and a runnable notebook on every one. Browse by what you are trying to do.
